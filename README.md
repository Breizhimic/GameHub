# GameHub

GameHub est un site vitrine qui rassemble une collection de jeux web accessibles depuis un navigateur. Il permet de découvrir les jeux du projet depuis une page d’accueil, avec une présentation de la collection et de ses statistiques.

Le site est réalisé en HTML, CSS et JavaScript sans framework.

[Jouer à GameHub](https://breizhimic.github.io/GameHub/)
